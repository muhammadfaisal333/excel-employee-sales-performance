# Employee Sales Performance Dashboard (Excel)

## Project Overview
This project focuses on analyzing weekly sales data for sales executives across multiple regions. The goal is to track total sales, evaluate performance against targets, and provide data-driven insights to help regional managers identify top performers and underperforming executives.

## Key Metrics Analyzed
* **Top 5 & Bottom 5 Sales Executives:** Identified by total revenue generated.
* **Top 5 Target Achievers:** Executives with the highest target-hit percentage.
* **Top 5 Furthest from Target:** Executives lagging furthest behind their set goals.

## Tools & Technical Features Used
* **Data Fields:** Employee Code, Sales Executive, Region, Daily Sales (Days 1-5), Total Sales, Target, Target Hit %, Away from Target %.
* **Pivot Tables:** Built 4 distinct dynamic matrices to calculate ranking metrics.
* **Data Visualization:** Integrated 2D/3D charts dynamically linked to performance tables.
* **Interactive Filtering:** Implemented regional **Slicers** to allow cross-filtering across all 4 reporting matrices simultaneously with a single click.

## Key Business Insights Derived
1. **Regional Variance:** Filtering by regions instantly exposes which geographical areas are hitting their collective targets and which areas need operational support.
2. **Performance Gap Analysis:** By monitoring the "Away from Target %", management can intervene early with underperforming executives before the end of a fiscal cycle.
